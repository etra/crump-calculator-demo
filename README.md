# Phone-Style Calculator

A fully functional phone-style calculator web app built with vanilla HTML, CSS, and JavaScript.

## Features

- Number pad (0-9, decimal point)
- Arithmetic operations (+, −, ×, ÷)
- Equals, Clear (AC), and backspace
- Percentage (%) and sign toggle (+/−)
- Responsive layout (mobile and desktop)
- Keyboard input support

## Getting Started

Open `index.html` in a modern browser — no build tools or server required.

## Project Structure

```
├── index.html          # Main HTML scaffold
├── css/
│   └── styles.css      # Styles, CSS reset, and custom properties
└── js/
    ├── engine.js       # Calculator logic (pure functions, no DOM)
    └── app.js          # UI wiring and event handling
```
